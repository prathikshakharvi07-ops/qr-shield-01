# 🛡️ QR SHIELD

### Scan Smart. Stay Safe.

**Your QR Code Security Companion**

QR Shield is a Java-based desktop security application designed to help users inspect QR code content and identify potentially suspicious or unsafe content before interacting with it.

---

## 🔐 Why QR Shield?

QR codes are convenient, but they can also hide potentially dangerous links and payment-related scams.

QR Shield helps users examine QR content and make safer decisions.

## ✨ Key Features

- QR code scanning and decoding
- Website URL security assessment
- Detection of potentially suspicious content
- Support for different QR content types
- Safety warnings and risk assessment
- Desktop interface built with Java Swing and AWT

## 💻 Technology Stack

| Technology | Purpose |
|---|---|
| Java 17 | Core application |
| Java Swing | Desktop interface |
| Java AWT | UI and graphics |
| ZXing | QR code processing |
| Maven | Build management |
